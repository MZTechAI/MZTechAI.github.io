## Flagship Disciplines & Capabilities

1. **Enterprise Software & Cloud Platforms**
   - Micro-frontend architecture, sub-second cold starts, distributed Redis caching, and RBAC governance.
2. **Generative AI, LLMs & Agentic Systems**
   - Fine-tuned domain models, zero-hallucination RAG document extraction, and LangGraph-governed human-in-the-loop state machines.
3. **MZ Sentinel AI Physical Security Operations**
   - Multi-camera RTSP/WebRTC triage, YOLOv10 60 FPS bounding-box inference, sensor correlation, and central station receiver integration (SIA DC-09, Contact ID, Manitou).
4. **Interactive Demos & Live Sandbox**
   - Real-time Document Q&A, Governed Agent Workflow Stepper, and Edge Computer Vision Triage simulator.
5. **Interactive Budget Estimator & RFP Intake**
   - Real-time client scope estimator, PDF/audit ledger logging, and 2-hour SLA response guarantees.

## Technology Stack

- **Frontend:** React 19, TypeScript, Vanilla CSS Cybernetic Design System (Fluid Typography, Glassmorphism).
- **Icons:** Lucide React
- **Audio Feedback:** Synthesized Web Audio API sound manager (operator alerts, telemetry clicks).
- **Build & Dev:** Vite 8.3, Oxlint.
- **CI/CD:** GitHub Pages & GitHub Actions.
